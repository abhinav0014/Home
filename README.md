## About Home 🏠

**Home** is a high-performance, dark-mode network utility for OpenWrt routers that prioritizes human-centric design and technical efficiency.

* **Abstraction Dictionary:** Completely hides low-level Linux hardware terms (`wlan0`, `eth1`). Every interface can be renamed to a friendly custom label in the settings.
* **Hybrid Network Architecture:** * **XHR Polling Engine:** Fetches real-time bytes over standard OpenWrt `ubus` HTTP APIs every 2 seconds to draw fluid bandwidth graphs with zero router CPU strain.
    * **SSH Configuration Engine:** Spawns an on-demand, secure terminal tunnel to execute bulletproof UCI commands when changing passwords or toggling networks.
* **Nordic Tech Aesthetics:** A beautiful, dark-mode first interface utilizing Material Design 3 principles, thin typography, and clean SVG telemetry indicators.
